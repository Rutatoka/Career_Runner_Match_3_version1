Ранер Карьеры

О проекте

Динамичный мобильный WebGL-раннер, разработанный для запуска непосредственно в браузере смартфона. Никаких скачиваний из сторов — игра загружается в один клик и адаптируется под вертикальный экран твоего устройства.

Разработчик

Ангелина Лунина (LunAV) — профессиональный разработчик игр и преподаватель IT-дисциплин.

Технологии

  • Игровой движок: Unity 2D/3D
  • Язык логики: C# (ООП)
  • Платформа сборки: WebGL (HTML5, WebAssembly)
  • Облачный хостинг: Yandex Cloud Object Storage
